# Circle Pill Defect Detection Dataset VOC+YOLO format with 330 images in 3 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 330

Number of annotations (number of xml files): 330

Number of annotations (number of txt files): 330

Label category count: 3

Label category names (note that the order of yolo format categories does not correspond to this, but is based on the labels folder's classes.txt): ["pill_blackspot", "pill_crack", "pill_normal"]

Number of boxes labeled in each category:

Pill_blackspot Frames = 138

pill_crack frame count = 44

pill_normal frame count = 148

Total frame count: 330

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
